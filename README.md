# Cobyism Tap

## How do I install these formulae?

`brew install cobyism/tap/<formula>`

Or `brew tap cobyism/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "cobyism/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
